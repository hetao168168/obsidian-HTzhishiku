# A股资金流 · 报告索引

> 本目录固定存放 A股板块资金流向报告（数据源：东方财富；资金主体：机构 / 主力 / 散户 / 大户）。
> 下方表格由 Dataview 自动汇总，打开即刷新。

## 全部报告
```dataview
TABLE file.mtime AS 更新时间
FROM "A股资金流"
WHERE file.name != "A股资金流索引"
SORT file.mtime DESC
```

- `A股资金流/日报/` — 每日资金流报告固定落点（在此新建笔记会自动套用「A股板块资金流报告」模板）
